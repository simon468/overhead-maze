# A Maze, A Maze, A Maze

Open dist/index.html in a WebGL-capable browser. Three.js r160 and its MIT license are bundled, so the game also works offline.

Choose Start playing on the welcome screen. Use WASD, arrow keys, or the on-screen buttons to move the cyan lantern. Reach the magenta beacon to unlock a larger, randomly generated maze. Restart returns you to the entrance of the same maze.

The camera follows the lantern through the maze. Your trail fades over 25 seconds. Collect a lime diamond in a dead end for a five-second overview. Keep moving during the overview while the run timer is paused.
